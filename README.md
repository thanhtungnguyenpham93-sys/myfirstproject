# Miền An — tải game Windows

[Tải Miền An Windows x64.zip](https://github.com/thanhtungnguyenpham93-sys/myfirstproject/raw/refs/heads/mien-an-download/Mien-An-Windows-x64.zip)

Giải nén ZIP, mở Mien-An-1.0.0-Windows-x64.exe trên Windows 10/11 64-bit. Không cần cài Python hoặc trình duyệt; game chạy offline.

Bản chưa ký số nên Windows có thể cảnh báo nhà phát hành chưa xác minh. Đã kiểm tra game và Electron trên Linux; chưa chạy trực tiếp trên Windows.
